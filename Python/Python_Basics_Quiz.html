1️⃣ Python Basics
1 Which of the following is the correct file extension for a Python source file? Basics
  • A) .python
  • B) .py
  • C) .pt
  • D) .pyt
Answer: B) .py
Python source files use the .py extension. Example: hello.py
2 What is the output of the following code? Basics
print(2 ** 3)
print(10 // 3)
print(10 % 3)
  • A) 8, 3.33, 1
  • B) 8, 3, 1
  • C) 6, 3, 1
  • D) 8, 3, 0
Answer: B) 8, 3, 1
** is exponentiation (2³ = 8).
// is floor division (10 ÷ 3 = 3).
% is modulus / remainder (10 % 3 = 1).
3 Which symbol is used for single-line comments in Python? Basics
  • A) //
  • B) /* */
  • C) #
  • D) --
Answer: C) #
In Python, single-line comments start with the hash symbol #. Multi-line comments are usually written using triple quotes """ ... """.
4 What will be the output of this code? Basics
x = 5
y = "5"
print(x + int(y))
  • A) 55
  • B) 10
  • C) Error
  • D) 5 5
Answer: B) 10
int(y) converts the string "5" into integer 5. Then 5 + 5 = 10.
2️⃣ Data Types
5 What is the data type of the value 3.14 in Python? Data Types
  • A) int
  • B) float
  • C) double
  • D) decimal
Answer: B) float
Numbers with a decimal point are of type float in Python. There is no separate double type like in some other languages.
6 Which of the following is a mutable data type in Python? Data Types
  • A) tuple
  • B) str
  • C) list
  • D) int
Answer: C) list
Lists are mutable (can be changed after creation). Tuples, strings, and integers are immutable.
7 What will be the output of the following code? Data Types
data = [10, 20, 30, 40]
print(data[1:3])
  • A) [10, 20]
  • B) [20, 30]
  • C) [20, 30, 40]
  • D) [10, 20, 30]
Answer: B) [20, 30]
Slicing data[1:3] means start at index 1 and go up to (but not including) index 3. So it returns elements at index 1 and 2.
8 Which of the following creates a dictionary in Python? Data Types
  • A) d = [1, 2, 3]
  • B) d = (1, 2, 3)
  • C) d = {1: "one", 2: "two"}
  • D) d = {1, 2, 3}
Answer: C) d = {1: "one", 2: "two"}
Dictionaries use curly braces with key:value pairs.
{1, 2, 3} creates a set. Lists use [], tuples use ().
9 What is the output of this code? Data Types
a = (1, 2, 3)
print(type(a))
  • A) <class 'list'>
  • B) <class 'tuple'>
  • C) <class 'set'>
  • D) <class 'dict'>
Answer: B) <class 'tuple'>
Parentheses () create a tuple. Tuples are ordered and immutable.
10 What does the following code print? Data Types
s = "Python"
print(s[0], s[-1], len(s))
  • A) P n 6
  • B) P o 6
  • C) y n 5
  • D) P n 5
Answer: A) P n 6
s[0] → first character 'P'
s[-1] → last character 'n'
len(s) → 6
3️⃣ Conditional Statements (if / elif / else)
11 What will be the output of the following code? Conditionals
x = 15
if x > 10:
    print("Greater")
elif x == 15:
    print("Equal")
else:
    print("Smaller")
  • A) Greater
  • B) Equal
  • C) Smaller
  • D) Greater Equal
Answer: A) Greater
The first condition x > 10 is True, so "Greater" is printed. The elif and else blocks are skipped once a true condition is found.
12 Which keyword is used for multiple conditions in Python? Conditionals
  • A) else if
  • B) elseif
  • C) elif
  • D) elsif
Answer: C) elif
Python uses elif (short for "else if") to check multiple conditions. There is no else if or elseif keyword.
13 What is the output? Conditionals
num = 7
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
  • A) Even
  • B) Odd
  • C) 7
  • D) Error
Answer: B) Odd
7 % 2 equals 1 (not 0), so the condition is False and the else block executes → "Odd".
14 What will this code print? Conditionals
a = 10
b = 20
print("Yes") if a < b else print("No")
  • A) Yes
  • B) No
  • C) True
  • D) Syntax Error
Answer: A) Yes
This is a ternary (conditional) expression. Since a < b is True, it prints "Yes".
15 Predict the output: Conditionals
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
print(grade)
  • A) A
  • B) B
  • C) C
  • D) D
Answer: B) B
score = 85 is less than 90 but greater than or equal to 80, so the second condition is True and grade becomes "B".
4️⃣ Loops (for & while)
16 What is the output of this code? Loops
for i in range(3):
    print(i, end=" ")
  • A) 1 2 3
  • B) 0 1 2
  • C) 0 1 2 3
  • D) 1 2
Answer: B) 0 1 2
range(3) generates numbers from 0 up to (but not including) 3 → 0, 1, 2.
17 How many times will the following loop run? Loops
count = 0
while count < 5:
    print(count)
    count += 1
  • A) 4 times
  • B) 5 times
  • C) 6 times
  • D) Infinite times
Answer: B) 5 times
count goes from 0 → 1 → 2 → 3 → 4. When count becomes 5, the condition count < 5 becomes False and the loop stops. So it runs 5 times.
18 What does the break statement do inside a loop? Loops
  • A) Skips the current iteration
  • B) Terminates the loop immediately
  • C) Restarts the loop from the beginning
  • D) Does nothing
Answer: B) Terminates the loop immediately
break exits the loop completely. continue skips the rest of the current iteration and moves to the next one.
19 What will be printed? Loops
for i in range(1, 6):
    if i == 3:
        continue
    print(i, end=" ")
  • A) 1 2 3 4 5
  • B) 1 2 4 5
  • C) 1 2
  • D) 3 4 5
Answer: B) 1 2 4 5
When i == 3, the continue statement skips the print for that iteration. So 3 is not printed.
20 What is the output of this nested loop? Loops
for i in range(2):
    for j in range(2):
        print(i, j)
  • A) 0 0
        0 1
        1 0
        1 1
  • B) 0 0
        1 1
  • C) 0 1
        1 0
  • D) Error
Answer: A)
Outer loop runs for i = 0 and i = 1.
For each i, inner loop runs for j = 0 and j = 1.
So the pairs printed are: (0,0), (0,1), (1,0), (1,1).
