What are Operators? Basics

Operators are symbols used to perform operations on values/variables. Arithmetic operators handle math operations like addition, subtraction, multiplication, etc. Python has 7 arithmetic operators.

The 7 Arithmetic Operators
+ Addition 15 + 4 = 19
− Subtraction 15 - 4 = 11
* Multiplication 15 * 4 = 60
/ Division 15 / 4 = 3.75
** Power/Exponent 15 ** 4 = 50625
// Floor Division 15 // 4 = 3
% Modulo 15 % 4 = 3
Division vs Floor Division vs Modulo

These three are often confused. Here's the key difference:

  • / → Returns the full decimal result: 15 / 4 = 3.75
  • // → Discards the decimal part, returns only the integer quotient: 15 // 4 = 3
  • % → Returns the remainder only: 15 % 4 = 3,  10 % 3 = 1
a = 15
b = 4
print(a /  b)  # 3.75  — real division
print(a // b)  # 3     — floor division (drop decimal)
print(a %  b)  # 3     — modulo (remainder)
print(a ** b)  # 50625 — 15 to the power 4
What is an Expression? Concept

An expression is any instruction written using operators and operands. In c = a + b, the variables c, a, b are operands and =, + are operators.

Operator Precedence PEMDAS / BODMAS

When multiple operators appear, Python evaluates them in a fixed order (highest → lowest):

#OperatorSymbolAssociativity
1Parentheses( )Inner first
2Exponent**Right → Left
3Multiplication / Division / Modulo* / // %Left → Right
4Addition / Subtraction+ -Left → Right
5Comparison== != < >Left → Right
6Logicaland or notLeft → Right
7Assignment= += -=Right → Left

d = (2+3) * 5    # () first → 5*5 = 25
d = 2*3 + 8/2   # * and / first → 6+4 = 10
d = 2**3**2       # ** is right-to-left → 2**(3**2) = 2**9 = 512
d = 3*4*5/4    # same precedence → left to right

Q1. What does 15 % 4 evaluate to?
✓ Correct! 15 ÷ 4 = 3 remainder 3. Modulo returns the remainder.
Q2. What is the result of 2 + 3 * 5?
✓ Correct! * has higher precedence than +, so 3*5=15 first, then 2+15=17.
Q3. What does 15 // 4 return?
✓ Correct! Floor division discards the fractional part and returns an integer.
Q4. a = 5; a += 3 — what is the value of a?
✓ Correct! a += 3 is shorthand for a = a + 3 → 5 + 3 = 8.
Q5. What is the result of 2 ** 3 ** 2 in Python?
✓ Correct! ** is right-associative: 3**2=9 first, then 2**9=512.
Q6. Which operator has the HIGHEST precedence?
✓ Correct! Parentheses always have the highest precedence in Python.
