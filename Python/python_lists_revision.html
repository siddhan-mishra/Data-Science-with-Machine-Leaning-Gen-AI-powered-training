# Slicing: list[start : stop : step]
L = [10, 20, 30, 40, 50]
L[1:4]    # → [20, 30, 40]
L[:3]     # → [10, 20, 30]
L[::2]    # → [10, 30, 50]
L[-1]     # → 50  (last element)
Empty slice tip: L[0:0] is an empty slice — refers to the space before index 0.

➖ REMOVING ELEMENTS

05

Traversal Methods

# 1. Simple for loop
for item in mylist:
    print(item)

# 2. for + enumerate()  ← Pythonic ✓
for i, item in enumerate(mylist):
    print(i, item)

# 3. while loop (manual index)
i = 0
while i < len(mylist):
    print(mylist[i])
    i += 1
Prefer enumerate() when you need both index and value — cleaner and more Pythonic than managing an index variable manually.

07

List Comprehension

Concise one-liner to create a new list from an existing one.

# Syntax: [expression for item in iterable if condition]

squares   = [x**2 for x in range(5)]         # [0,1,4,9,16]
evens     = [x for x in L if x % 2 == 0]     # even numbers
odds      = [x for x in L if x % 2 != 0]     # odd numbers

# Filter valid positive sales
sales = [100, 250, -50, 400, "error", 300]
cleaned = [x for x in sales if isinstance(x, int) and x > 0]
08

Nested Lists

A list containing other lists — used to represent matrices, grids, or tables.

# 2D nested list (matrix)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

matrix[0][1]   # → 2  (row 0, col 1)
matrix[2][2]   # → 9  (row 2, col 2)

# Traverse with nested loops
for row in matrix:
    for val in row:
        print(val, end=' ')
