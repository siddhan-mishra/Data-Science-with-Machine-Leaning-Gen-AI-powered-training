if Statement

Basic

The if statement checks a condition. If the condition is True, the indented block of code runs. If it's False, nothing happens and Python moves on.

Start
condition?
True ✓
Execute Block
False ✗
Skip Block
Continue

Syntax:

if condition:
    # code runs only when condition is True
    statement

Example:

age = 20

if age >= 18:
    print("You are an adult.")

# age (20) >= 18 → True → block executes
▶ Output
You are an adult.
↔️

if-else Statement

Two Paths

The else clause provides an alternative block that executes when the if condition is False. Exactly one of the two blocks always runs.

Syntax:

if condition:
    # runs when condition is True
    block_A
else:
    # runs when condition is False
    block_B

Example — checking even or odd:

number = 7

if number % 2 == 0:
    print(f"{number} is Even")
else:
    print(f"{number} is Odd")

# 7 % 2 = 1 → condition False → else runs
▶ Output
7 is Odd

Example — password check:

password = "secret123"
user_input = "wrongpass"

if user_input == password:
    print("✅ Access Granted!")
else:
    print("❌ Wrong password. Try again.")
▶ Output
❌ Wrong password. Try again.
🔀

elif Statement

Multiple Branches

elif (short for "else if") lets you chain multiple conditions. Python checks each condition in order — the first one that is True wins, and the rest are skipped.

if    → checked first
elif → checked if if was False
elif → checked if above were False
else → runs if all above were False

Syntax:

if condition_1:
    block_1
elif condition_2:
    block_2
elif condition_3:
    block_3
else:
    block_default
